
# CompliTrack

**A Simple Compliance and Document Reminder Platform for Small Businesses**

CompliTrack is a web-based prototype designed to help small businesses organise compliance tasks, manage important documents, and track upcoming deadlines from one dashboard.

## Features

- Add, update, and delete compliance tasks
- Set due dates for tasks
- Track Pending and Completed tasks
- Identify overdue, due-soon, and upcoming deadlines
- Search tasks and filter by status
- Upload, download, and delete business documents
- View dashboard statistics and basic reports

## Technology Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Anshika-K-S/CompliTrack.git
   ```

2. Open the project folder:
   ```bash
   cd CompliTrack
   ```

3. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   ```

   Windows Git Bash:
   ```bash
   source venv/Scripts/activate
   ```

4. Install Flask:
   ```bash
   pip install Flask
   ```

5. Run the application:
   ```bash
   python app.py
   ```

6. Open this address in your browser:
   `http://127.0.0.1:5000`

## Project Scope

This is an academic prototype. Deadline reminders are displayed on the dashboard; automated email or SMS notifications are not currently implemented. The platform does not provide legal advice or automatically verify legal compliance requirements.

## Future Scope
